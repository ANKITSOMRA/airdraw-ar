HOW TO USE

  • ☝️ Index Up — Draw on canvas
  • ✊ Fist — Stop drawing / lift pen
  • ✌️ Two fingers — Erase mode
  • 🖐 Open hand — Clear canvas (hold 2s)
  • 👍 Thumb Up — Cycle brush color
  • ↖ Swipe Left — Undo last stroke
  • Ctrl+Z — Undo (keyboard)
  • Space — Pause / Resume
  • S — Save drawing
💡 If index finger isn't detected, the most extended finger is used automatically.
